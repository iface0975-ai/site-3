СЕЛЕКТОР — школа діджеїнгу. Файли сайту.

Структура:
  index.html      — головна сторінка
  css/style.css   — стилі
  js/main.js      — інтерактив (платівка, стрілка, відгуки-сповіщення)
  img/            — фото, картинки, favicon
  video/hero.mp4  — фонове відео на першому екрані

Як запустити:
  1. Netlify Drop: відкрий app.netlify.com/drop і перетягни ВСЮ папку.
  2. Звичайний хостинг: завантаж вміст папки в public_html (або www),
     щоб index.html лежав у корені.
  3. GitHub Pages: закинь усі файли в репозиторій і увімкни Pages.

Важливо: завантажуй папки css, js, img, video разом з index.html —
без них сайт буде без стилів і картинок.

Перед запуском:
  - Постав свої посилання Telegram / Instagram (index.html, шукай t.me та instagram.com).
  - Під'єднай форму заявки (зараз вона нікуди не надсилає дані).
  - Заміни відгуки на справжні, а картинки менторів — на фото реальних викладачів.
